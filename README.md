# serverless-cdk

🚧 Work in progress...

A battle-tested serverless boilerplate based on AWS CDK, extracted from the shareNOTE project.

## Quick Start (Coming Soon)

```bash
npx create-serverless-cdk my-app
cd my-app
npm install
npm run deploy:dev
```

## Features

- Lambda + API Gateway + DynamoDB + S3
- TypeScript/Node.js 20.x
- Environment-based deployment strategies
- Built-in best practices from real production experience
